# 发布与同步

仓库：https://github.com/xiaolubbstudio/xczstudio

已发布的网址：https://xiaolubbstudio.github.io/xczstudio/

2026-09-27 首次发布完成，GitHub Pages 的构建状态为 built，使用 main 分支根目录。线上网页已在浏览器打开，上传入口包含已配置的 pCloud 连接。

网站由 GitHub Pages 提供，成员上传的素材直接保存在 pCloud；本机无需一直开机。

## 成员登录配置

采用各自的 pCloud 账号，由文件夹共享权限决定是否可以上传。目录继续公开浏览。

1. 在 https://docs.pcloud.com/my_apps/ 申请“雷霆素材库”应用，Website 填线上网址，Folder access 选择 All folders，Write access 选择 yes。官方授权范围覆盖账号文件；本站仅操作配置的素材文件夹。
2. 回调地址设置为 https://xiaolubbstudio.github.io/xczstudio/auth.html 。批准后只把 Client ID 写入 data/catalog.js，不要提供或保存 Client Secret。
3. 在 pCloud 中停用旧的文件请求链接，并关闭公开分享链接的上传选项。代码和 Git 历史中去掉链接不能代替服务端撤销。
4. 对素材文件夹使用 Invite to folder，邀请指定成员，并授予上传权限。成员先接受邀请，再在网站登录。全部账号须使用美国数据区。
5. 登录令牌只保存在当前标签页会话，退出或关闭标签页后清除。每次上传由 pCloud 再次校验成员权限。

应用未配置时网站会暂停上传，不使用匿名入口作为备用方式。应用审批和旧链接停用状态须由管理员确认后，才可宣布指定成员上传已完整生效。

## 后续修改

用户已要求：每次网站修改完成后验证并推送到仓库，同时检查线上部署结果。此约定记录在项目根目录 AGENTS.md。

1. 获取 origin/main 最新状态并保留远端改动。
2. 修改网站，在本地预览验证相关行为。
3. 按改动范围运行语法检查、连接测试或只读集成检查。
4. 检查 git diff，只提交需要发布的代码，不包含技能包、截图或原始素材。
5. 提交并推送到 origin/main。
6. 检查 Pages 部署结果，并打开线上地址确认修改已生效。

网站代码修改需要同步仓库；素材上传和目录变化不需要提交代码，页面会直接读取 pCloud。

## 连接

本机 Git 使用 Git Credential Manager 登录，不在项目文件中保存密码或 token。

当前仓库 Git 代理为本机已有的 http://127.0.0.1:7897，只保存在本地 .git/config。关闭现有代理后如果不能访问 GitHub，需要恢复网络连接或调整本地配置。

仓库为公开仓库。当前版本没有成员登录系统；网站及上传入口可被访问者使用。

## 初次开启 Pages

仓库 Settings → Pages → Source 选择 Deploy from a branch，Branch 选择 main，目录选择 /(root)，保存。开启后的构建和部署由 GitHub 完成，后续推送会触发更新。
