# 发布与同步

仓库：https://github.com/xiaolubbstudio/xczstudio

GitHub Pages 开启并部署成功后的地址：https://xiaolubbstudio.github.io/xczstudio/

网站由 GitHub Pages 提供，成员上传的素材直接保存在 pCloud；本机无需一直开机。

## 后续修改

用户已要求：每次网站修改完成后验证并推送到仓库，同时检查线上部署结果。此约定记录在项目根目录 AGENTS.md。

1. 获取 origin/main 最新状态并保留远端改动。
2. 修改网站，在本地预览验证相关行为。
3. 按改动范围运行语法检查、连接测试或只读集成检查。
4. 检查 git diff，只提交需要发布的代码，不包含技能包、截图或原始素材。
5. 提交并推送到 origin/main。
6. 检查 Pages 部署结果，并打开线上地址确认修改已生效。

网站代码修改需要同步仓库；素材上传和目录变化不需要提交代码，页面会直接读取 pCloud。

## 连接

本机 Git 使用 Git Credential Manager 登录，不在项目文件中保存密码或 token。

当前仓库 Git 代理为本机已有的 http://127.0.0.1:7897，只保存在本地 .git/config。关闭现有代理后如果不能访问 GitHub，需要恢复网络连接或调整本地配置。

仓库为公开仓库。当前版本没有成员登录系统；网站及上传入口可被访问者使用。

## 初次开启 Pages

仓库 Settings → Pages → Source 选择 Deploy from a branch，Branch 选择 main，目录选择 /(root)，保存。开启后的构建和部署由 GitHub 完成，后续推送会触发更新。
